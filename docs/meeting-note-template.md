# Meeting note template

This file is a reference template for manual use in Obsidian.

It is not meant to be embedded or generated by the plugin. The plugin is responsible only for synchronization.

## Recommended template

```md
---
sopSync: true
sopType: meeting
sopDomain: executive
noteId: 20260312104530-a7k2
sopId:
meetingDate: 2026-03-12
lastSyncedAt:
lastSyncStatus:
---

# Reunião semanal Quest

## Objetivo
Definir prioridades da semana e destravar pendências de operação.

## Participantes
- Rafael
- Ana
- João

## Decisões
- Priorizar revisão do funil comercial
- Adiar contratação até abril

## Tarefas
- [ ] Rafael: revisar métricas até sexta
- [ ] Ana: consolidar pauta da próxima reunião

## Notas
Observações livres da reunião.
```

## Required metadata for sync

- `sopSync: true`
- `sopType: meeting`
- `sopDomain: executive` or `creator`
- `noteId`
- `meetingDate`

## Required content for sync

- note title
- markdown body

## Notes

- `noteId` can be created manually for tests, but the plugin will generate and persist one automatically if the note is otherwise eligible for sync.
- Section titles may be written in Portuguese or English.
- The full markdown body is sent to the SOP API. The plugin does not need to extract each section into separate fields in V1.
